### About

I am a final-year Electrical Engineering student at UET Lahore working in machine learning research. My current focus is AI safety and evaluation: how LLM agents fail silently, and how deterministic checks and reproducible evaluation can catch those failures. I also work on state space models for sequence modeling.

I care about careful experimental design: pre-registered gates, honest reporting of limitations, and results that can be reproduced from stored outputs without re-running the models.

**Research interests**
- **AI safety and evaluation:** reliability and verification of tool-using LLM agents, adversarial testing
- **Sequence modeling:** selective state space models (Mamba) for long-range temporal dependencies

### Featured Projects

| Project | Summary | Stack |
|---|---|---|
| [**Read-Back Verification in LLM Agent Pipelines**](https://github.com/ayeshaazulfiqar/REPO_NAME) | Evaluation study of how storage faults and wrong-but-faithfully-stored decisions silently corrupt multi-step LLM agent pipelines. Read-back with retry cut silently wrong orders from 47.2% to 0.1% under storage faults, but left 26.7% silently wrong on Gemma decisions; a deterministic re-check of the rule reduced this to 0%. Fully reproducible from stored results, with pre-registered gating and documented limitations. Built at the Swarm Alignment Hackathon (Apart Research). | Python, DeepSeek, Gemma, Adaption API |
| [**Scam Shield**](https://github.com/ayeshaazulfiqar/Scam_Shield) ([live demo](https://scamshieldapp-gw873grbsmcqdnx8p7qhet.streamlit.app/)) | Tool-using LLM agent that checks suspicious SMS, WhatsApp messages and screenshots in English, Roman Urdu and Urdu. A URL analyzer and pattern matcher feed evidence to Gemini for a structured JSON verdict. 100% accuracy on a 50-message test set. | Python, Gemini API, Prompt Engineering, Regex |
| [**Gauntlet**](https://gitlab.com/gitlab-ai-hackathon/transcend-october-2026/43672348/showcase) | Multi-agent GitLab merge pipeline: a Builder agent proposes fixes, a Breaker agent writes adversarial tests, and an evidence gate blocks merges that lack audit evidence. Adversarial tests caught 4 of 4 seeded bugs, versus 0 of 4 for the starter tests. | GitLab Duo, CI/CD, SAST, Python |
| [**AI Allergen Detection**](https://github.com/ayeshaazulfiqar/AI_based_food_allergen_detection_using_vlms) | Multi-label allergen risk assessment for unpackaged foods, combining an ANN (0.74 Macro F1), MobileNetV2 and Gemini Vision. Deployed as a Streamlit app with image and text input. | Python, CNN, VLM, Streamlit |
