### 💜 About Me

**I build ML systems that are tested properly, explained clearly, and actually useful.**

I'm a final-year Electrical Engineering student at UET Lahore, specializing in Machine Learning and Deep Learning. I like projects where a model has to do a real job: spotting scams in Urdu, flagging allergen risks from food photos, or checking whether AI-written fixes really work.

**🔭 What I'm into right now**
- 🤖 **LLM agents:** tool-using agents with structured outputs and honest evaluation
- 👁️ **Computer vision and multimodal models:** images, text and vision-language models working together
- 🧪 **Testing ML properly:** hidden test sets, adversarial tests, and reporting what didn't work

**💬 Ask me about:** PyTorch, CNNs, Gemini API, prompt engineering, or building a first LLM agent

**🌍 Fun fact:** I build for Urdu speakers as well as English ones. Loss curves going down are my happy place 📉
